# ADR-0004. Детерминированная заглушка LLM по умолчанию

**Статус:** принято · **Дата:** 2026-09-24

## Контекст
Тесты и CI не должны зависеть от внешнего API и денег на балансе; `docker compose up` не должен требовать ключа.

## Решение
Порт `LlmClient` в модуле `llm` с адаптерами `StubLlmClient` (по умолчанию), `OpenAiCompatibleLlmClient` (`AIEX_LLM_PROVIDER=openai`) и `OllamaLlmClient` (`ollama`, тот же OpenAI-совместимый протокол).
Заглушка собирает ответ из характерных фраз, которые модуль `persona` кладёт в системный промпт строками `- «фраза»`, и выбирает фразу по хешу сообщения — одинаковый вход даёт одинаковый ответ. Маркеры `[[llm:timeout]]` и `[[llm:down]]` в тексте сообщения имитируют таймаут и недоступность провайдера — так на защите показывается деградация в `503` без отключения сети.

## Последствия
- Ни один тест не ходит в реальный LLM; демо проходит без внешней сети.
- «Живая» генерация включается одной переменной среды.
